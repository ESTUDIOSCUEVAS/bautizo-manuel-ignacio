# Bautizo de Manuel Ignacio Loya Naranjo

Propuesta web en azul, marfil y dorado con ilustración safari tipo grabado.

## Vista previa
Abre index.html en el navegador. La ilustración está integrada dentro del archivo. Las tipografías requieren conexión y tienen fuentes alternativas.

## Publicar en Cloudflare Pages
Sube el contenido descomprimido a la raíz de un repositorio nuevo. En Cloudflare Pages conecta el repositorio: rama main, Framework None, Build command vacío y Build output directory /. No requiere instalación ni compilación.

## Datos pendientes
- Fecha real: se muestra sábado 20 de febrero de 2027 como ejemplo, señalado en la propuesta.
- Enlaces exactos de Maps del Santuario de Guadalupe y Campestre Santa Bárbara.
- Confirmación de asistencia, si se desea agregar.
- Dominio final para configurar la vista previa de WhatsApp.

Misa: 12:00 p. m. Celebración: 2:00 p. m.

## Editar
Los textos, estilos y animaciones se encuentran en index.html. Las imágenes están incorporadas como datos; no modificar esas cadenas. La ilustración original se incluye en assets/safari.jpg como respaldo.
